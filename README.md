The Medical Data History project focuses on analysing patient, doctor, admission and province-related information using SQL. The main objective is to understand how medical data can be retrieved, organised and analysed from a database. I worked with different SQL commands to filter records, sort data, calculate totals and identify useful patterns. The project also involved grouping data, using aggregate functions and joining multiple tables to obtain meaningful information. Through these tasks, I gained practical experience in writing SQL queries and working with relational databases. Overall, this project helped me improve my SQL skills and understand how databases can be used to manage medical information.
